# Период полураспада. Что стало с наукоградами России

Интерактивное дата-исследование о 13 официальных наукоградах России, 35 годах статистики науки, федеральных деньгах и забытых мегапроектах — от тоннеля УНК под Протвино до синхрофазотрона в Дубне.

## Что внутри

- `index.html` — текст и структура лонгрида (8 глав + методология)
- `app.js` — интерактивная графика (D3 v7): скроллителлинг-фасад, карта городов науки с лупой на Подмосковье, диаграмма сроков статуса, динамика персонала науки, возрастная структура исследователей (скроллителлинг), федеральная поддержка (план/исполнение) и тепловая карта по городам, население по переписям, кольца ускорителей в масштабе, архив мегапроектов
- `data.js` — все данные одним объектом `window.DATA` (собирается скриптом из CSV)
- `data/*.csv` — исходные таблицы для скачивания
- `img/` — фотографии с Wikimedia Commons (лицензии и авторы указаны на карточках)
- `style.css` — оформление

Сайт статический: никакого бэкенда, достаточно открыть `index.html` или включить GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий, загрузите содержимое папки целиком (включая `.nojekyll`).
2. Settings → Pages → Source: `Deploy from a branch`, branch `main`, folder `/ (root)`.
3. Через минуту сайт доступен по адресу `https://<username>.github.io/<repo>/`.

Перед публикацией замените `[ИМЯ АВТОРА]` в подвале `index.html` на своё имя и укажите ссылку на канал.

## Источники

- Федеральный закон № 70-ФЗ «О статусе наукограда РФ» в редакциях 1999–2025 гг., указы Президента и акты Правительства о присвоении и продлении статуса (publication.pravo.gov.ru, kremlin.ru/acts/bank, static.government.ru)
- Законы о федеральном бюджете на 2000–2028 гг. и об исполнении бюджета за 2001–2024 гг.
- ИСИЭЗ НИУ ВШЭ: «Индикаторы науки» 2007–2026, «Российская наука в цифрах» (2018), экспресс-информации 2021–2026; Росстат, раздел «Наука»; ЦИСН (1997–1998)
- Переписи населения 1959–2021 и оценки Росстата (через Wikidata, P1082)
- Союз развития наукоградов России (карта «Наукограды России»)
- Публикации ИФВЭ (PAC95, EPAC96, RuPAC 2008), УФН, ОИЯИ, NASA, buran.ru, ПРАО ФИАН, ИЯИ РАН и СМИ — для раздела «Музей несбывшегося»

Полный список с оговорками — в разделе «Методология» на сайте.
